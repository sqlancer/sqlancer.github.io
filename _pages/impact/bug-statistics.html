Further breakdowns of the same {{ stats.bugs.total }} accepted bug reports the impact page counts. Each system's own page lists the individual reports behind its share.

Which technique found them

SQLancer is an umbrella: alongside the main tool, components such as SQLancer++ and ShQveL count towards these figures. Each record keeps both the tool that found the bug and, where the report says so, the specific technique — they are never collapsed into one label. “Technique not recorded” means the report identifies the campaign but not which oracle fired.
